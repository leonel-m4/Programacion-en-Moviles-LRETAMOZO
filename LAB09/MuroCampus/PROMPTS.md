## Revisión de las reglas

Antes de cada commit se revisó el código propuesto:

- No hay `catch` vacíos: todo pasa por `llamar`, que relanza `CancellationException` y devuelve `Result.failure` para lo demás.
- No se usa `GlobalScope`: todas las corrutinas usan `viewModelScope`.
- La URL base es `https://`; no hay ningún `http://`.
- Ninguna pantalla (`ui/`) llama a `RetrofitClient` ni a `PostApi`.
- `PostsViewModel` no importa Retrofit, `PostApi`, `HttpException` ni `Context`.
